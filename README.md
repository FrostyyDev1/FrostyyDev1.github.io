# Jacob Wiseman

Personal site for Jacob Wiseman, IT support in Elkview, West Virginia. Static build for GitHub Pages at [frostyydev1.github.io](https://frostyydev1.github.io).

This site is built on the [portfolio template by Emeric Guyon](https://github.com/emricooo/portfolio-emeric-guyon) (Nuxt 3, Vue 3, Tailwind 4, GSAP). The template is MIT licensed. Copyright (c) 2026 Emeric Guyon. See [LICENSE](./LICENSE).

## Develop

```bash
npm install
npm run dev
```

## Static site

```bash
npm run generate
```

The generated site is written to `.output/public`. The base URL is `/`, which is correct for a GitHub user site.
