# Jacob Wiseman

Static portfolio for IT support, desktop support, and systems and networking roles. Built with Next.js and exported for GitHub Pages.

```bash
npm install
npm run dev
npm run lint
npm run build
```

The production build writes the site to `out/`. Deployment runs from `.github/workflows/deploy-pages.yml` on pushes to `main`.

Pages: home, about, experience, certifications, contact, and a terminal-style 404.
