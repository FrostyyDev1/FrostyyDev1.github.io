02 Process

How a job moves

The same four steps on every machine, from the previous site.

Method

Diagnose. Repair. Verify.

  1. 01

    Understand

    Listen to the problem and understand what the user is actually experiencing.

  2. 02

    Diagnose

    Isolate the likely cause using testing, observation, and logical troubleshooting.

  3. 03

    Resolve

    Apply the repair, configuration change, upgrade, or solution that addresses the cause.

  4. 04

    Verify

    Test the system afterward to make sure the issue is actually resolved.

03 Scope

What the work includes

The kinds of work named on the previous site. Specific settings and part lists belong in the job stories below.

  1. 01

    Diagnostics

    Find the cause of a hardware, software, performance, or reliability problem before replacing parts.

  2. 02

    PC repair

    Repair desktops with hardware failures, configuration problems, or software issues, then confirm the system is stable.

  3. 03

    Custom builds

    Plan and assemble a desktop around a budget and workload: compatible parts, assembly, firmware, software, and a stability check.

  4. 04

    Upgrades

    Check that a part fits the rest of the system, then test that the machine is stable afterward.

  5. 05

    Optimization

    Look at startup programs, storage, thermals, and configuration, and fix the measured cause instead of a generic tweak.

  6. 06

    Malware removal

    Identify and remove unwanted software, check for related damage, and confirm the system is updated and stable.

  7. 07

    Remote support

    Troubleshoot software, connectivity, and configuration with the person using the computer, and explain the steps in plain language.
